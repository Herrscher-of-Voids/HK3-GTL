# 当前多方块设计规则

更新：2026-10-02，依据用户最新要求。

- 自由重设计造型与风格，不沿用旧 V1 造型或尺寸上限。
- 占地尺寸下限保留，以 `structure_size_baseline.py` 读取的69座占地总表为准。现有检查同时保留宽、深、高下限。
- 导出前检查声明尺寸与实际方块边界，逐轴不得低于下限；不能通过扩大空白导出范围代替实体尺寸。
- 正式机器名字不改。
- 逐台独立选材，使用当前项目16色电压机壳与测试包跨模组建材；不能反复套用同一组外壳。颜色与功能分区配合，避免为数量无目的堆砌。
- 各台接口候选位置统一使用 `hk3gtl:industrial_port_casing` 作为封闭填充块。它本身没有物品、流体或供能能力；接入正式 Pattern 时需按接口用途允许相应真实仓室替换，并单独校验必需能力。
- 建筑外观以现实设备的功能分区组织：主体设备、输入输出、热交换、管线、维护通道和检修平台要能从造型辨认。预览中的工艺路线是造型设定，不能据此宣称游戏运行逻辑已接通。
- I01-2 至 I01-4 在前一阶基础上扩建，仅替换控制器，不拆除前一阶建筑。
- 已确认建筑保存为独立时间戳归档及 ZIP，记录确认状态与 SHA256；接入游戏时读取对应确认版本，不能静默替换。
- 预览通过不代表游戏 Pattern、配方或生存可达性已验收。

共享导出入口：`build_redesign69.export`。归档入口：`archive_reviewed_structures.py`，会重新读取实际 NBT 检查尺寸。
