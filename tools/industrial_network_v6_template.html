I14 的多用途工艺，围绕聚合、压力成形与共固结展开

  • 结构坯：包覆纳米群 + 金属骨料 + 前驱液 → 粗魂钢坯，送I15、I16。
  • 承压坯：合格组织料 + 耐热骨料 + 对应模具 → 燃料组件承压壳坯，送封装与耐压件制造。
  • 复合框坯：魂钢组织料 + 约束陶瓷嵌件 → 空间锚承力坯，送退火、精加工和组件装配。
  • 智能夹层：维修纳米群 + 复合层材 + 隔离界面 → 可维修复合板坯，送稳定化与防护工程。
  • 回收料路线：已分选失活返料 + 新鲜基元/骨料 → 降级或合格坯料；不可直接恢复全部组织与质量。

全部为物品与工艺关系草案，不含冻结投料比、EU/t、温度或时长；不同族需要不同材料条件，不只复制配方后改输出名。

另一个汇流实例：控制组件不靠“魂钢 + 电路 = 一切”

  1. 共享基底：GT晶体制备、切片，按模式分流为逻辑、存储、功率等工艺分支；沿用整合包现有工艺和最终模式覆盖。
  2. 三路独立供料：N16提供功能基膜/封装树脂，N14提供互连箔，N09提供微执行或传感组件。不同功能不强制塞入完全相同的一套投料。
  3. 分用途装配：GT加工晶圆并组装基板；控制型汇入逻辑与存储，驱动型汇入功率器件，传感型汇入阵列组件。
  4. 特殊环境适配：需要耐侵蚀的器件经I13隔离封装，魂钢壳与载体基底由I16供给；普通电路无需强制绕这段。
  5. 多出口：控制板供无人作业，功率模块供电力装备，传感模块供测量硬件与后期阵列。返修走N26，材料回收走N25，不用“一块万能板”包办所有功能。

这里借鉴的是当前整合包的工艺组织，尚未改变任何现有GT电路配方、替换脚本或电路等级。
