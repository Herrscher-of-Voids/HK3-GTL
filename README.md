# HK3-GTL

崩坏三 × 格雷科技现代版扩展模组，面向 GTL 整合包的终局及 MAX 后阶段，包含崩坏能工业、文明研究与巨构设施等内容。

当前源码版本：`0.5.0`（内测5），同步日期：`2026-11-11`。运行环境：Minecraft `1.20.1`、Forge `47.4.16`、Java `17`；当前兼容测试目标为 GTL 增强版 `3.5`。

## 使用

`releases/HK3GTL-内测5-20261111.jar` 为本次同步的构建产物，与本地增强版3.5实例安装包逐字节一致，SHA256见同名 `.sha256` 文件。旧 `0.4.0-beta.1` 产物保留作历史。

本次包含三段谐振式崩坏能网络注入器（41×45×33、8,152块）、正式控制器、终端搭建计划和自有JEI预览。构建及离线核验通过；本次注入器尚未完成游戏内完整搭建、成型、运行及自然零HW起步验收，不能视为已完成这些测试。其他系统仍为内测状态。

请备份存档后，将新版放入配齐前置模组的实例 `mods/` 目录。同一实例只保留一份HK3GTL。依赖声明见 `src/main/resources/META-INF/mods.toml`。

## 构建

准备 Java `17`、Python `3`（可从 `python` 命令调用）和 Python 包 `numpy`，按 `libs/README.md` 放置本地依赖后运行：

```powershell
.\gradlew.bat build
```

Linux/macOS 可运行 `bash gradlew build`。构建结果位于 `build/libs/`。

52份原始结构JSON以逐文件gzip保存在 `source_archives/approved_architecture/`。构建先校验压缩包SHA256，再流式恢复原始资源，核对原始字节数和SHA256；原文件已有不同内容时拒绝覆盖。恢复文件已被Git忽略，不能再次上传。NBT、预览流、Java源码、资源、测试与构建脚本均保留，未用缩小版结构替换原件。首次恢复至少预留10GB磁盘空间。

仓库不分发第三方依赖JAR、游戏存档、认证配置、本地审计与交付历史。完整依赖需自行准备；不能在缺少这些依赖时直接构建。
